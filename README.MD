# Extreme Forging Additions

Extreme Forging Additions is an add-on for MITE-ITE that extends the ITE forging table with modifier-related features inspired by Extreme Remastered.

## Features

- Adds forging templates for copper, silver, gold, iron, ancient metal, mithril, adamantium, and vibranium equipment.
- Adds extra forging table modes for upgrading, defusing, applying, and normal forging.
- Allows equipment modifiers to be defused into material-matching forging templates.
- Allows stored modifiers on forging templates to be applied back to compatible tools or armor.
- Adds configurable modifier gain counts and per-modifier draw weights for equipment level-ups.

## Configuration

The config screen is available through ManyLib / ModMenu.

By default, equipment level-ups draw 1 modifier. The 2, 3, and 4 modifier gain options are disabled by default and can be enabled by increasing their weights.

Tool and armor modifier weights can also be configured individually. Higher weights make a modifier more likely to be drawn, while `0` prevents that modifier from being randomly gained.

## Requirements

- FishModLoader `>= 3.0.0`
- ManyLib `>= 2.3.0`
- Rusted Iron Core `>= 1.5.0`
- MITE-ITE `>= 2.0.27`
